# Back on Board – Public Transport in Australia

FIT3179 Data Visualisation 2 (Monash University, Semester 2 2026).

- `index.html` – the page (open with Live Server, or via GitHub Pages)
- `css/styles.css` – layout, colour and typography
- `js/vega_lite_vis.js` – embeds every chart with a shared style
- `js/*.vg.json` – one Vega-Lite specification per chart (16 files)
- `data/` – cleaned CSV and TopoJSON files (sources and processing in `data_processing_notes.md`)
- `sketch/sketch.pdf` – hand-drawn sketch (add yours here)
